# Command Line Task Manager

Command Line Task Manager is a modular Python console application for managing personal tasks.

The project demonstrates a simple layered architecture with repositories, services and renderers while keeping all data locally.

## Features

- Task listing
- Priority levels
- Completed / pending status
- Due date support
- Task statistics
- JSON export

## Example

```
Task List

[ ] Finish documentation
Priority: High
Due: 2026-08-01

[x] Buy groceries
Priority: Low
Due: 2026-07-24

Summary

Total tasks: 4
Completed: 2
Pending: 2
```

Run

```bash
python main.py
```
